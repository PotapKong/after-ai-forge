# Role card: verifier

Owns: `docs/verify/**`

Independently check whether the work is actually done. Run the app, commands,
tests, browser flow, HTTP smoke, or build that best matches the acceptance
criteria. Do not change code.

Output:

- `docs/verify/<feature>.md`
- PASS or FAIL
- commands run and key output
- blockers, regressions, and unverified areas
